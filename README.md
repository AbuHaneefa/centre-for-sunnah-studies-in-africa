# Centre for Sunnah Studies in Africa

Static bilingual website for the Centre for Sunnah Studies in Africa.

## Open locally

Open `index.html` for the English website or `ar/index.html` for the Arabic (RTL) website.

## Edit content

- English content: `index.html`
- Arabic content: `ar/index.html`
- Shared styling: `styles.css` and `overrides.css`
- Arabic RTL styling: `ar/ar.css`
- Images: the `.jpg` files in this folder

Keep the English and Arabic versions aligned when programme information changes.

## Publish updates

After editing, commit and push your changes:

```powershell
git add .
git commit -m "Describe the update"
git push
```

Your hosting provider can be connected to this repository for automatic deployment after every push.
